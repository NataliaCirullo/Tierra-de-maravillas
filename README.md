# Tierra de Maravillas

Boceto funcional de una landing page para presentar el proyecto **Tierra de Maravillas**.

## Objetivo

Comunicar una propuesta centrada en naturaleza, calma y experiencias significativas, usando una interfaz minimalista, clara y responsive.

## Tecnologias

- HTML
- CSS
- JavaScript

## Estructura del proyecto

```text
.
├── assets/
│   └── .gitkeep
├── css/
│   └── styles.css
├── images/
│   ├── hero-placeholder.svg
│   └── logo-placeholder.svg
├── js/
│   └── main.js
├── index.html
└── README.md
```

## Secciones incluidas

- Header con logo placeholder, nombre del proyecto y navegacion.
- Hero con imagen placeholder de naturaleza, frase inspiradora y CTA.
- Quienes somos con descripcion del proposito del proyecto.
- Propuestas con 3 tarjetas y boton de consulta.
- Contacto con botones directos a WhatsApp e Instagram.
- Footer con enlaces y mensaje final.

## Caracteristicas implementadas

- Estilo minimalista, moderno y limpio.
- Paleta natural (verdes suaves, beige, blanco y tonos tierra).
- Tipografia elegante y legible.
- Diseno responsive para movil y escritorio.
- Animaciones suaves de entrada y revelado al hacer scroll.
- Menu movil funcional.

## Como ejecutarlo

1. Clonar o descargar este repositorio.
2. Abrir la carpeta en VS Code.
3. Abrir `index.html` en el navegador.

## Placeholders

- `images/logo-placeholder.svg`: logo temporal.
- `images/hero-placeholder.svg`: imagen temporal para la seccion principal.

Puedes reemplazar estos archivos por imagenes finales manteniendo los mismos nombres para no modificar rutas.
